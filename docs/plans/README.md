# Plans

Dated task-plan records. One file (or folder, when a plan accumulates phases,
logs, or decisions) per plan, named `YYYY-MM-DD-title.md`. Open the plan record
at the start of the work and keep its checklist current as the work proceeds —
it is the live goal of record, not an afterword. This index carries links and
status summaries only; details live in the plan files.

Plans here are public repo artifacts: use generic placeholders
(`alice-example`, `acme-example`, `fund-a`) and include a privacy-risk line for
plans that touch external services or local runtime state. Private scratch
plans belong outside the repo.
