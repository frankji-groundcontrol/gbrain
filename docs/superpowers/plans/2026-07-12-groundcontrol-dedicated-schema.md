# Groundcontrol Dedicated Schema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an explicit `postgres_schema: "groundcontrol"` mode that lets the restricted `groundcontrol_app` role own, initialize, migrate, and use only the `groundcontrol` schema while preserving every legacy Postgres and PGLite path.

**Architecture:** Add one fixed-mode configuration and URL-normalization module, pass the complete normalized `EngineConfig` through every host connection path, and add fail-before-DDL preflight and final verification to `PostgresEngine`. Reuse the canonical schema and migration registry with narrow dedicated-mode rendering and selection. Do not add a second schema, migration framework, privileged credential, arbitrary-schema abstraction, or advisory-lock redesign.

**Tech Stack:** TypeScript, Bun, postgres.js, PostgreSQL 16 with pgvector and pg_trgm, Supabase pooler URLs, Bun test, Docker E2E, generated `schema-embedded.ts` and llms bundles.

**Approved design:** `docs/superpowers/specs/2026-07-12-groundcontrol-dedicated-schema-design.md`

**Dependencies:** Task 1 blocks Tasks 2 and 3. Task 3 blocks Task 4. Task 4 blocks Task 5A. Task 5A blocks Tasks 5B and 6. Tasks 2, 3, 5B, and 6 block Task 7. Task 7 blocks Task 8. Task 8 blocks Task 9.

**Scope guard:** Leave the existing untracked `generate_*_fixtures.ts` files untouched. Stage explicit paths only. Current TypeScript diagnostics for unused and deprecated symbols in `postgres-engine.ts` predate this plan and are out of scope unless a changed line directly requires their removal.

- [ ] **Step 4: Implement `src/core/postgres-dedicated.ts`**

```ts
import { redactConnectionInfo } from './audit/redact-connection-info.ts';

export const DEDICATED_SCHEMA = 'groundcontrol' as const;
export const DEDICATED_SEARCH_PATH = 'groundcontrol,extensions';

export type DedicatedEngineConfig = {
  database_url?: string;
  direct_database_url?: string;
  postgres_schema?: 'groundcontrol';
};

export function isDedicatedSchemaMode(cfg: { postgres_schema?: string }): boolean {
  return cfg?.postgres_schema === DEDICATED_SCHEMA;
}

function canonicalizeSearchPath(raw: string): string {
  // URL-decode, split on comma, trim whitespace, drop empties.
  const parts = decodeURIComponent(raw).split(',').map(s => s.trim()).filter(Boolean);
  if (parts.length !== 2) throw redactedError('search_path must have exactly two schemas');
  const [a, b] = parts;
  if (a !== 'groundcontrol' || b !== 'extensions') {
    throw redactedError('search_path must be groundcontrol,extensions');
  }
  return DEDICATED_SEARCH_PATH;
}

function redactedError(message: string): never {
  throw new Error(`[groundcontrol] ${redactConnectionInfo(message)}`);
}

function normalizeUrl(url: string | undefined): string | undefined {
  if (!url) return url;
  // postgres:// and postgresql:// - URL needs an http scheme for WHATWG parsing.
  const http = url.replace(/^postgres(ql)?:\/\//, 'http://');
  const parsed = new URL(http);
  const params = new URLSearchParams(parsed.search);
  const existing = params.get('search_path');
  if (existing) {
    const canonical = canonicalizeSearchPath(existing);
    if (canonical !== existing) {
      params.set('search_path', canonical);
    }
  } else {
    params.set('search_path', DEDICATED_SEARCH_PATH);
  }
  // Reject duplicate search_path keys.
  const keys = [...parsed.searchParams.keys()].filter(k => k === 'search_path');
  if (keys.length > 1) throw redactedError('duplicate search_path query parameter');
  parsed.search = params.toString();
  // Restore original scheme.
  const scheme = url.match(/^postgres(ql)?:\/\//)?.[0] ?? 'postgres://';
  return scheme + parsed.toString().replace(/^https?:\/\//, '');
}

export function normalizeDedicatedPostgresConfig<C extends DedicatedEngineConfig>(config: C): C {
  if (!isDedicatedSchemaMode(config)) return config;
  const database_url = normalizeUrl(config.database_url);
  const direct_database_url = config.direct_database_url
    ? normalizeUrl(config.direct_database_url)
    : config.direct_database_url;
  // Agreement: both must resolve to the same effective first schema. Since
  // normalization forces the canonical path, a non-throwing result means they
  // agree. A throw on either closes both before any pool opens.
  return { ...config, database_url, direct_database_url };
}
```

Note: the WHATWG `URL` constructor may not accept `postgres://` directly on all runtimes; the http-swap shim above is the same pattern `connection-manager.ts:110` and `:134` already use. Verify the restored scheme round-trips by adding a round-trip assertion to the test.

```ts
private async runDedicatedPreflight(conn: ReturnType<typeof postgres>): Promise<void> {
  const rows = await conn<{
    current_user: string; current_schema: string; pg_version: number;
    schema_owner: string; has_connect: boolean;
    has_usage_public: boolean; has_usage_extensions: boolean;
    can_create_public: boolean; can_create_extensions: boolean;
    has_create_groundcontrol: boolean;
    rolsuper: boolean; rolbypassrls: boolean; rolcreatedb: boolean;
    rolcreaterole: boolean; rolreplication: boolean;
    vector_schema: string | null; pg_trgm_schema: string | null;
  }[]>`
    SELECT
      current_user, current_schema() AS current_schema,
      (regexp_split_to_array(current_setting('server_version'), '\.'))[1]::int AS pg_version,
      (SELECT nspowner::regrole::text FROM pg_namespace WHERE nspname = 'groundcontrol') AS schema_owner,
      has_database_privilege(current_database(), 'CONNECT') AS has_connect,
      has_schema_privilege(current_user, 'public', 'USAGE') AS has_usage_public,
      has_schema_privilege(current_user, 'extensions', 'USAGE') AS has_usage_extensions,
      has_schema_privilege(current_user, 'public', 'CREATE') AS can_create_public,
      has_schema_privilege(current_user, 'extensions', 'CREATE') AS can_create_extensions,
      has_schema_privilege(current_user, 'groundcontrol', 'CREATE') AS has_create_groundcontrol,
      rolsuper, rolbypassrls, rolcreatedb, rolcreaterole, rolreplication
      FROM pg_roles WHERE rolname = current_user
    LIMIT 1
  `;
  // vector + pg_trgm placement:
  const ext = await conn<{ extname: string; schema: string }[]>`
    SELECT e.extname, n.nspname AS schema
    FROM pg_extension e JOIN pg_namespace n ON e.extnamespace = n.oid
    WHERE e.extname IN ('vector', 'pg_trgm')`;
  const r = rows[0]!;
  const checks: [boolean, string][] = [
    [r.current_user === 'groundcontrol_app', 'current_user must be groundcontrol_app'],
    [r.current_schema === 'groundcontrol', 'current_schema must be groundcontrol'],
    [r.schema_owner === 'groundcontrol_app', 'groundcontrol must be owned by groundcontrol_app'],
    [r.pg_version >= 13, 'PostgreSQL 13+ required'],
    [r.has_connect, 'role lacks CONNECT'],
    [r.has_usage_public, 'role lacks USAGE on public'],
    [r.has_usage_extensions, 'role lacks USAGE on extensions'],
    [!r.can_create_public, 'role must not have CREATE on public'],
    [!r.can_create_extensions, 'role must not have CREATE on extensions'],
    [r.has_create_groundcontrol, 'role lacks CREATE on groundcontrol'],
    [!r.rolsuper, 'role must not be superuser'],
    [!r.rolbypassrls, 'role must not have BYPASSRLS'],
    [!r.rolcreatedb, 'role must not have CREATEDB'],
    [!r.rolcreaterole, 'role must not have CREATEROLE'],
    [!r.rolreplication, 'role must not have REPLICATION'],
  ];
  for (const [ok, msg] of checks) if (!ok) throw new Error(`[groundcontrol] preflight: ${msg}`);
  const vector = ext.find(e => e.extname === 'vector');
  const trgm = ext.find(e => e.extname === 'pg_trgm');
  if (!vector || vector.schema !== 'extensions') throw new Error('[groundcontrol] vector must be in extensions');
  if (!trgm || trgm.schema !== 'public') throw new Error('[groundcontrol] pg_trgm must be in public');
}
```
