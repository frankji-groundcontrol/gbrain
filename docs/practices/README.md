# Practice records

Reusable setups, module patterns, command sequences, and operational methods —
the "how we do this here" that a task reveals. At task completion, decide
whether a practice was learned; if yes, record it here before closing.

Conventions:

- One practice per file: `YYYY-MM-DD-title.md`; use a folder
  `YYYY-MM-DD-title/` when examples, scripts, or variants will grow.
- Write the practice so it can be followed without the original task's
  context: preconditions, the steps, and how to verify.
- Redact private identifiers to placeholders before writing — these records
  are public repo artifacts.
- Update this README's list when adding or changing practices.

Boundary with neighbors: ship-critical IRON RULES stay inline in
[`../../CLAUDE.md`](../../CLAUDE.md) (its own maintenance section mandates
this); agent-facing operating conventions live in
[`../../skills/conventions/`](../../skills/conventions/); this folder holds
contributor-facing practices that don't need to load every session.
